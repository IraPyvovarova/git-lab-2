Лабораторна робота №2

Тема
Створення та налаштування репозиторію на GitHub, відстеження змін у проєкті.

Мета роботи
Закріплення навичок роботи із системою контролю версій Git та платформою GitHub: ініціалізація локальних репозиторіїв, управління комітами, робота з гілками та синхронізація даних із віддаленим сховищем.

Короткий опис виконання
1. **Ініціалізація та налаштування:** Створено локальний репозиторій за допомогою `git init`, підготовлено робочі файли (`README.md`, `info.txt`, `plan.txt`).
2. **Керування версіями:** Здійснено додавання файлів через `git add` та створено перші коміти за допомогою `git commit`.
3. **Відстеження змін:** Оновлено файл `info.txt`, перевірено зміни через `git diff` та зафіксовано нову версію.
4. **Робота з віддаленим репозиторієм:** Створено репозиторій на GitHub, виконано прив'язку локального проєкту (`git remote add origin`) та відправлено код за допомогою `git push`.
5. **Гілкування та злиття:** Створено гілку `experiment`, додано нові теми в `plan.txt`, після чого виконано об'єднання гілок за допомогою команди `git merge`.
